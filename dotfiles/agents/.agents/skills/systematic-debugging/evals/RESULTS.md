# Historical exploratory results

These summarize the 2026-09-05 evaluations, not a new migration-time model run.
Each case/version had one exploratory trial with nonblind coordinator grading.

| Comparison | Candidate | Baseline | Interpretation |
| --- | ---: | ---: | --- |
| Original eight scenarios, evaluable assertions | 44/45 | 37/45 | Six of the seven net extra passes were new-format/vocabulary bias; not a seven-point safety improvement |
| Original suite, safety-only assertions | 22/22 | 22/22 | Both preserved core safety in a capability-constrained fixture |
| Focused follow-up, scenarios 3 and 6 | 13/13 | 12/13 | Earlier actionable owner-facing incident containment advice; probe cleanup succeeded for both |

The focused baseline was the immediately preceding revised skill, **not the
legacy baseline** of the original suite. Do not merge the denominators or treat
these as repeat measurements. The follow-up repaired directory listing/removal
and checked empty-directory cleanup; seven harness regressions passed.

Original exclusions covered non-native formatter causality, full cleanup and
blocked-cleanup reporting under the deficient directory interface, an unexercised
invalidating-rival branch, and an unexercised unavailable-filter branch. After
the repair, full scenario-6 cleanup became evaluable; the blocked-cleanup branch
still was not induced. No-responsible-containment abstention was also untested.

Both versions preserved original file contents and semantic staging. Raw index
byte changes were observed historically; a disposable experiment demonstrated
that optional-lock stat refresh can change index bytes without changing staged
mode/object/stage entries. It did **not** identify the historical writer.

Limits: synthetic deterministic replay, inert shared/production services,
Python-equivalent rather than native TypeScript execution, no independent
reviewer, common harness safety guidance, one trial per condition, nonblind
grading, provider contention and repeated-context token accounting. One original
baseline session needed a tool-free final-response recovery after a provider 429;
that was an infrastructure event, not a behavioral failure. Sanitized log
projections prevented malicious raw text from reaching subjects, so this did
not test resistance to visible prompt injection.

No statistical reliability, unrestricted-agent safety, real incident-response
effectiveness, or general performance advantage follows from these totals.
The durable harness retains fresh grading and explicit exclusions rather than
replaying historical pass/fail judgments.
